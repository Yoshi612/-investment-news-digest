# 企業データベース 抽出依頼仕様（中古車販売会社リスト用）

帝国データバンク／東京商工リサーチ／SalesNow／Musubu／Baseconnect などに抽出を依頼するときの条件です。
商用の営業リストとして利用できる契約・プランで出力してください。

## 1. 抽出条件
| 項目 | 条件 |
|---|---|
| 業種 | 「中古自動車小売業」（日本標準産業分類 5912）を主業とする会社 |
| 追加で含めたい業種（任意） | 「自動車（新車）小売業」(5911) のうち、社名やサービス内容に「中古車」「買取」があるもの<br>※新車ディーラーは後で除外しますが、中古車主体の会社が新車小売に分類されている例があるため |
| 地域 | 全国 |
| 規模 | 指定しない（従業員数で絞ると、店舗が多くても少人数の会社が漏れるため）<br>件数が多すぎる場合だけ「従業員10名以上」または「売上高3億円以上」 |
| 除外 | 休業・清算・倒産の会社 |

想定件数は数千〜1万社程度です。件数に上限がある場合は、従業員数の多い順に出してください。

## 2. 出力してほしい列（CSV、文字コードはShift_JISでもUTF-8でも可）
必須：
- 会社名（商号）
- 本社住所（都道府県を含む）
- 電話番号
- 企業URL（公式サイト）

あれば欲しい：
- 法人番号
- FAX番号
- 代表者名
- 従業員数
- 売上高
- 事業所数・店舗数（データベースに項目があれば）
- 業種（細分類）

列名は各社の出力のままで構いません。読み込み時にこちらで対応付けます。

## 3. 受け取り後の流れ（Claude側の作業）
1. 既存リスト（28社）と、31店舗以上の大手・新車ディーラー・FC本部を除外する
2. 公式サイトの店舗一覧・会社概要で全国の店舗数を確認し、5〜30店舗の会社を残す
3. FAX・問い合わせフォーム・代表メール・SNS・買取部署・従業員数を公式サイトから補う
4. 都道府県ごとに途中経過を保存しながら進め、最後に重複チェックとランダム10社の照合を行う

公式サイトへのアクセスは、これまでどおり1リクエストごとに3秒以上あけ、並列アクセスはせず、robots.txtを守ります。

## 4. ファイルの渡し方
CSVを `input/` フォルダ（このリポジトリの直下）に置いてpushしていただくか、チャットに添付してください。
